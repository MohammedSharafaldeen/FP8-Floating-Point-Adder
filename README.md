# FP8-Floating-Point-Adder
## Overview

This project implements an FP8 (8-bit floating-point) adder using Verilog HDL. The design performs floating-point addition by handling exponent alignment, mantissa arithmetic, normalization, and overflow/underflow conditions. The implementation was exhaustively verified using all **65,536 possible input combinations**, achieving **zero errors**, demonstrating the correctness and reliability of the hardware design.
